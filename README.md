# 🚀 Asteroids (Python)

A classic arcade-style **Asteroids** game built with Python! Control a spaceship, dodge floating space debris, and blast asteroids to get the highest score possible.

> **Note:** This was my very first game project built while learning Python game development!

---

## 🎮 Features

* **Physics & Movement:** Smooth rotation, thrust acceleration, and screen-wrapping mechanics.
* **Shooting System:** Fire lasers to destroy incoming space rocks.
* **Asteroid Splitting:** Larger asteroids break down into smaller, faster pieces when hit.
* **Score & Lives Tracker:** Keep track of your high score and remaining lives.
* **Game Over & Restart:** Game over screen with the ability to quickly restart.

---

## 🛠️ Prerequisites & Requirements

Before running the game, make sure you have the following installed on your machine:

* **Python 3.x** (Python 3.8 or higher recommended)
* **Pygame** (or whichever library you used)
